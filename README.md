# StudyFlow MVP

StudyFlow 是一个优先适配手机浏览器的本地学习管理网页。首版使用普通 HTML、CSS 和 JavaScript，不需要安装框架，也不连接数据库。

## 打开方式

开发预览地址：`http://127.0.0.1:4174/`

只要本地预览服务仍在运行，在 Codex 的浏览器标签中打开或刷新这个地址即可看到最新版本。

## 推荐试用流程

1. 在“进度”中创建科目。
2. 创建学习项目，可填写总数量和已经完成的数量。
3. 在主页或“进度”中创建今天的任务。
4. 从任务右侧的计时按钮开始学习，结束时保存学习记录、题量、错题数和对应项目。
5. 单独勾选任务完成状态，然后在主页和“统计”查看变化。
6. 在“复盘”中按科目写复盘并选择或新增错误原因标签。
7. 在“日记”中打卡、随手记、回答自定义问题，并通过时间轴回看当天。

## 数据保存

`main` 分支仍是本地存储版本：数据保存在当前浏览器的 `localStorage` 中，并支持 JSON 备份。

账号登录与云端同步正在 `feature/auth-cloud-sync` 分支开发。要测试该分支，请先按 `SUPABASE_SETUP.md` 配置 Supabase 公开密钥、认证回调地址和数据库表。不要把数据库密码或 `service_role` 密钥放进前端代码。

## 文件

- `index.html`：页面结构。
- `styles.css`：手机端界面与响应式样式。
- `app.js`：业务逻辑、统计、计时恢复和本地存储。

## 当前限制

- 暂无登录、云同步和多人使用。
- 暂无 AI 自动提炼、AI 建议和系统通知。
- 本地预览地址只能在当前电脑的预览环境中访问；以后部署到公网后，手机才可在电脑关机时继续访问。
